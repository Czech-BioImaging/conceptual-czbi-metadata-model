# CzBIRD Conceptual Model

...nicknamed as **CCMM_REMBI_CzBIRD**.

Two backup files (from [Dataspecer](https://dataspecer.com/)) of the CzBIRD conceptual
model, a REMBI-derived metadata model, constitue the model itself and is available here.

The main file is `CCMM_REMBI_CzBIRD_AP_1.0.zip`, which holds the conceptual
model and its application profile. Since an adequate profile was unfortunately not
found for a very small number of classes of the conceptual model, their vocabulary
is thus defined in another file, `CCMM_REMBI_CzBIRD_voc_1.0.zip`.

Exported specification of this CzBIRD [is available](https://github.com/Czech-BioImaging/bioimaging-metadata-model-specification)
and rendered here at:

[**https://czech-bioimaging.github.io/bioimaging-metadata-model-specification/en/**](https://czech-bioimaging.github.io/bioimaging-metadata-model-specification/en/)
